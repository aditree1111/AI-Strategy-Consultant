# AI Strategy Consultant

An AI-powered business analytics dashboard that analyzes company annual reports and generates strategic insights.

## Features

- Upload any public company's Annual Report (PDF)
- Extract and clean PDF text
- Split reports into AI-ready chunks
- Interactive Streamlit dashboard
- Foundation for Retrieval-Augmented Generation (RAG)

## Tech Stack

- Python
- Streamlit
- PyMuPDF
- Regular Expressions
- Git & GitHub
