# AI Strategy Consultant

An AI-powered strategy consulting application that analyzes public company annual reports using Retrieval-Augmented Generation (RAG).

## Features

- Upload annual report PDFs
- Extract and clean text
- Semantic chunking
- Vector search using ChromaDB
- AI-powered question answering with Gemini
- Company Overview generation
- SWOT Analysis
- Business Risk Analysis
- Growth Opportunities
- Strategic Recommendations

## Tech Stack

- Python
- Streamlit
- Google Gemini
- ChromaDB
- Sentence Transformers
- PyMuPDF
- RAG

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
